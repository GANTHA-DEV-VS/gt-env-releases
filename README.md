# GT-ENV pour Windows

GT-ENV est l’application de modélisation acoustique environnementale de Gantha. Ce dépôt distribue les installateurs Windows du module EQ.

**[Télécharger la dernière version](https://github.com/GANTHA-DEV-VS/gt-env-releases/releases/latest)**

Sur la page de la version, choisissez le fichier `GT-ENV-Setup-<version>.exe`. Si GT-ENV est déjà installé, l’application peut télécharger la mise à jour et vous proposer de l’installer après l’enregistrement de votre étude. Si vous utilisez la 0.37.0 distribuée en privé, installez la 0.37.1 manuellement une fois pour réactiver les mises à jour automatiques.

La bibliothèque Gantha reste soumise à la validation d’un compte. Vous pouvez demander l’accès depuis l’application.
